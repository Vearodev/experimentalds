# Вкладки и соответствие ДС · 0.6.3

## Причина расхождений

Быстрые представления реестров были отдельными Button с прикладными стилями. Форма использовала Tabs, но её CSS менял фон и отступы списка. Таблица получала собственные размеры иконок, кнопок, подписи, радиус и оформление заголовка. Одни только ссылки на системные цвета не обеспечивали соответствия компонентам ДС.

Дополнительно пять общих правил для полей, кнопок и таблицы находились в стилях плейграунда. Они перенесены в библиотеку UI: компонент должен выглядеть одинаково без подключения CSS каталога.

## Единый визуальный источник

Каталог, реестры ВМ, дисков, сетей, хостов и задач, страницы ВМ и проекта, а также форма создания используют один Tabs. Сохранены принятые в ДС подложка, индикатор, типографика и счётчик. Вложенные страницы не создают второго вертикального меню.

Приложение задаёт данные, внешнюю компоновку и навигацию. Внешний контейнер формы создаёт отступы, но не меняет список или панель вкладок. Цвет состояния ресурса остаётся в StatusBadge и подсветке строки; состояние навигации не окрашивается в цвет ошибки.

| Параметр                    | Компонентный токен            | Источник                        |
| --------------------------- | ----------------------------- | ------------------------------- |
| Высота 36 px                | `comp.tabs.item-height`       | `comp.button.size.md.height`    |
| Горизонтальный отступ 14 px | `comp.tabs.item-padding`      | `comp.button.size.md.padding`   |
| Подпись 14 px               | `comp.tabs.font-size`         | `comp.button.size.md.font-size` |
| Радиус 4 px                 | `comp.tabs.radius`            | `sys.radius.small`              |
| Промежуток 4 px             | `comp.tabs.gap`               | `sys.space.xs`                  |
| Подложка активной вкладки   | `comp.tabs.active-background` | `sys.color.surface.selected`    |
| Индикатор                   | `comp.tabs.active-indicator`  | `sys.color.brand.accent`        |
| Содержимое, отступ 24 px    | `comp.tabs.panel-padding`     | `sys.space.xl`                  |

Всего 18 токенов вкладок доступны в инспекторе компонента, включая счётчик, границу, толщину и отступ индикатора. Ссылки на Button отражают композицию: базовая кнопка → вкладка → реестр. Светлая и тёмная темы меняют общие цветовые роли.

## Представления и поведение

- «Все», «Работают» и другие сохранённые наборы условий переключают содержимое одной панели. Поиск сохраняется и участвует в счётчиках.
- Произвольные условия получают выбранную вкладку «По условиям». «Все» не выглядит активной при применённых фильтрах. Возврат в «Все» снимает условия и сохраняет поисковый запрос.
- Вкладка связана с панелью через доступное имя и `aria-controls`. Стрелки, Home и End меняют выбор и фокус. Недоступные вкладки пропускаются.
- При недостатке ширины прокручивается строка вкладок. Дополнительная подпись справа скрывается на узком экране; сам список не исчезает.
- Массовый выбор таблицы использует общую стабильную панель DataTable. Закрепление заголовка при прокрутке теперь относится к общему компоненту.

## Граница стилей

Проверка `design:check` входит в сборку. Она просматривает CSS обоих приложений и запрещает переопределения Tabs, DataTable, TableTools и ContextPanel. Разрешено только прикладное ограничение минимальной и максимальной высоты области прокрутки таблицы. Это целевая защита этих компонентов, а не полный аудит всех композиций приложения.

Состав колонок и ширина по смысловым ролям могут зависеть от данных. Скалярные числовые колонки демо используют токен 112 px, чтобы вместить стандартные кнопки сортировки и фильтра. Размеры самих кнопок, отступы ячеек и высота строк одинаковы с ДС. Пользовательской настройки плотности и ширины нет.
