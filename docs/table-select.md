# TableSelect · дизайн выбора ресурсов

Компонент нужен, когда по одному названию нельзя принять решение: диски, образы, узлы, сети и другие связанные ресурсы. Поле хранит подтверждённое значение; раскрывающаяся область предоставляет сравнение характеристик.

## Состав

- Триггер поля: имя первого ресурса и счётчик остальных; видимые подпись, подсказка и ошибка.
- Окно выбора: название задачи, режим выбора, поиск, переключатель на выбранные строки.
- Общая DataTable: границы всех столбцов, строки 40 px, заголовок 44 px, сортировка, пояснения полей, чекбоксы или радиокнопки.
- Футер: количество, снятие выбора, отмена, применение. Кнопки — общие Button/IconButton.

Ширина окна задаётся `comp.table-select.width` через семантическую роль 760 px. На узком экране она ограничивается доступным местом. Таблица прокручивается внутри, действия остаются доступны. Окно располагается рядом с полем, когда для этого достаточно места; иначе — в доступной области экрана.

## Поведение

| Сценарий                 | Результат                                                                |
| ------------------------ | ------------------------------------------------------------------------ |
| Открытие                 | Подтверждённый набор копируется в черновик; фокус получает поиск         |
| Множественный выбор      | Чекбоксы; нажатие на данные строки тоже меняет отметку                   |
| Одиночный выбор          | Радиокнопки; чекбокс «выбрать всё» отсутствует                           |
| Поиск и сортировка       | Отметки сохраняются по идентификаторам ресурсов                          |
| Выбрать всё              | Только доступные строки текущей выборки; прочие отметки сохраняются      |
| Недоступная строка       | Причина читается в данных; индивидуальный и массовый выбор её пропускают |
| «Выбранные»              | Отображается текущий черновик с учётом поискового запроса                |
| Снять выбор              | Очищается черновик, подтверждённое значение пока не меняется             |
| Применить                | Черновик становится значением поля; окно закрывается                     |
| Отмена, Escape, закрытие | Черновик отбрасывается; фокус возвращается в поле                        |
| Пустой результат         | Видимое объяснение и возможность очистить поиск                          |

Примеры отдельной страницы: одиночный/множественный режим, исходно выбранные значения, недоступное поле, загрузка, обязательный выбор с ошибкой, отсутствие ресурсов и длинное название.

В текущем прототипе данные локальные. Перед реализацией продуктовой библиотеки отдельно проектируются выбор по нескольким серверным страницам, лимиты выбора, исчезновение/изменение доступности ресурса во время запроса и виртуализация больших наборов. Локальный поиск не выдаётся за серверный.
